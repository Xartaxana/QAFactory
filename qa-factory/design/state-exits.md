# Every state the factory records, and the way out of it — 2026-09-28

Factory rule **FR-40**: *every state the factory can record has a sanctioned way out*. The rule
was written from one defect: a row entered `tests[]` and could leave only once every case it
proved had moved to `unresolved[]`, so a stale instance of an otherwise good case survived
forever and the only route left was a waiver on a defect. `manifest_put.py --fragment
{retracted_instances}` is that door, and a live role then retracted 8 rows on
TP1-13797 so the manifest matched collection, 9 = 9.

This is the walk of the rest. One row per state, the command that reverses it, and the test that
holds the door open. `scripts/tests/test_state_exits.py` enumerates the states from the source —
`controller.projection([])` for the story's own state, `contract` for the manifest's lists,
`waiver.py` for the person's records — so a **new** state cannot be added without a row here.

Read this when you add a state: a field that a story can sit in, and that nothing can take it out
of, is a dead end a person pays for.

## What this walk found

- **`stage_overrides[]` had no way out at all.** A person's word passes any block; nothing could

  exactly what `waiver.py` exists to replace. `--revoke` is that door now, and it appends rather
  than deletes: the story still shows the block was passed and when it stopped being.
- **`unknown_external_writes[]` has no writer.** Not a missing door — a missing fact. Recorded
  here so the next walk does not go looking for one.

  written down together, which is why `retracted_instances` was invented twice before it was
  found once.
